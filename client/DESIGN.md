# SI合宠 · 控制台设计备忘

沿用小小桌宠控制台布局：侧栏品牌 + 「我的角色」卡片列表，不改主页信息架构。

## 合宠相关约定

1. **主页**：WebM 角色卡负责显示开关；有 CrossPet 映射时增加「修改形象」。
2. **修改形象页**：只编辑当前锁定角色；可选「动作原版」或 CrossPet 衣服；不在此页开关桌宠。
3. **单引擎**：同一本体形象同一时间只开 WebM 或 CrossPet 一种。
4. **分身**：可独立形象；CrossPet 分身可多窗。
5. **无映射角色**（如 Gemini）：单独成卡，始终走 CrossPet。

桌宠右键菜单与动画链在 `resources/engine/runtime/electron-helper/`，不在本目录。

SI合宠 · 使用说明
================
让喜欢的 AI 陪在桌面上。
本软件是在开源项目上的二次开发，请先阅读文末「致谢与许可」。

一、怎么打开
-----------
1. 打开「SI合宠」整个文件夹（不要只复制 SI合宠.exe）。
2. 双击 SI合宠.exe。
3. 首次启动会连接本地桌宠服务；角色开关打开后，宠物会出现在桌面。
4. 关掉控制窗口后，宠物仍会运行。可从系统托盘再次打开，或选择「退出全部桌宠」。

二、主页：显示与隐藏
-------------------
1. 「我的角色」里每个角色有开关：开 = 显示在桌面，关 = 隐藏。
2. 可用「全部开启 / 全部隐藏」。
3. 点「查看动作」可点播 WebM 动作；「添加分身」可多开同角色实例（最多 8 个）。
4. 「显示大小」可调缩放，点「应用」生效。

三、修改形象（动作原版 / CrossPet）
--------------------------------
1. 有映射关系的角色卡片上有「修改形象」（例如蓝毛小女仆 ↔ DeepSeek）。
2. 进入后可选：
   - 「动作原版」：小小桌宠 WebM 动作桌宠；
   - CrossPet 各套衣服：立绘桌宠。
3. 同一形象同一时间只显示一种。改完回主页用开关控制显示。
4. 分身也可单独点「修改形象」，互不影响。
5. 没有 WebM 对应的 CrossPet 角色（如 Gemini）会单独出现在主页，只能用 CrossPet 形象。

四、桌面右键菜单（大肥鱼风格）
-----------------------------
在 WebM 桌宠上右键，可大致使用：
- AI 对话、碎碎念
- 看看屏幕 / 截图提问（需在设置里配置支持识图的模型与密钥）
- 播放动画（待机 / 转向 / 移动 / 点击 / 随机动作分组）
- 大小、播放速率、音乐媒体键
- 桌宠控制、快捷启动、待办、免打扰、天气、抽支签等
- 打开控制台、退出全部桌宠

五、设置
-------
1. 「API 与角色对话」：配置模型地址、密钥、记忆轮数（WebM 对话 / 碎碎念 / 看屏）。
2. 「接入 AI / 跟随」：CrossPet 跟随前台、工作事件、额度样式与部分钩子接入。
3. 看屏失败时，请确认密钥有效，并尽量使用支持图片输入的模型。
4. 隐私：看屏 / 截图提问会采集本机屏幕并可能发往你配置的第三方 API；仅限本人设备与合法用途，密钥勿泄露。

六、数据保存在哪
---------------
- WebM 角色与配置：%USERPROFILE%\.dsh\dsh-pet\
- CrossPet 状态：%LOCALAPPDATA%\SI-HeChong\

七、常见问题
-----------
Q：双击没反应 / 启动失败？
A：确认 resources、runtimes、resources\crosspet 仍与 exe 在同一套文件夹里；杀毒软件勿隔离。

Q：开了开关桌面上没有宠物？
A：看是否选了「动作原版」却关掉了 WebM，或选了 CrossPet 却未开显示；点「刷新」后再试。

Q：一直在连播动作、很少待机？
A：本版已加大待机权重。若仍偏快，可在角色配置里提高 animationWeights.idle，或右键开「免打扰」。

Q：CrossPet 与 WebM 叠了两个？
A：应不会；若遇到，对该角色点「修改形象」明确选一种，再回主页开关一次。

Q：分身能不能换形象？
A：可以。分身管理里点「修改形象」。
